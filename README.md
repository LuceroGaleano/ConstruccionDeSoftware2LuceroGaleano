# ConstruccionDeSoftware2LuceroGaleano
Este proyecto implementa un sistema bancario con fines académicos, enfocado en el aprendizaje de la arquitectura DDD.
Permite gestionar clientes, usuarios, cuentas bancarias, préstamos y transferencias, aplicando principios de modelado de dominio y lógica de negocio.

#Tecnologías utilizadas
  Java: Lenguaje principal utilizado para el desarrollo del sistema.
  Spring Boot: Framework que facilita el desarrollo de aplicaciones Java.
  Programación Orientada a Objetos (POO): Paradigma utilizado para la estrucutra de     clases y objetos.
  Domain-Driven Design (DDD): Enfoque arquitectónico.

#Instalación:
  1. Clonar el repositorio
  2. Abrir en un IDE.

#Uso
El proyecto cuenta con la implementación del domino y la lógica de negocio, serviendo como base para futuras integraciones.
